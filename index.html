Case study · Web app (PWA)

Qunor

The problem

I wanted a free way to learn to read the Quran that works anywhere: no account, no sign-up, and no internet needed once it has loaded.

What I built

  • All 114 surahs with word-by-word audio from 44 reciters
  • Qaida and tajweed lessons for complete beginners
  • Translations in 81 languages
  • Installable as an app, works offline

Key decisions

  • Built as a Progressive Web App so it installs on any phone without an app store
  • A Python check verifies the Quran text on every deploy, so a broken edit never goes live
  • No back end or accounts, which keeps it free to run and private for users

Built with

  • JavaScript
  • PWA
  • Service worker
  • Python
  • HTML
  • CSS

Case study · Web app

Driving Teaching

The problem

I teach driving. Lesson plans, pupil progress and mock test results were spread across paper and notes, with no single view of how close a pupil is to test standard.

What I built

  • A 37-session teaching route in 8 stages, each with a client-centred lesson plan
  • A 30-lesson A to Z curriculum with skills rated from Introduced to Independent
  • A digital mock test sheet laid out like the examiner's report, with a live pass or fail result
  • The official Show me, Tell me questions as flashcards, plus animated manoeuvre guides
  • Separate progress profiles for each pupil, with backup export and import

Key decisions

  • Plain JavaScript and Tailwind CSS with no build step, so it deploys instantly as a static site
  • All data stays on the device in localStorage, so there is no login and no pupil data on a server
  • Light, dark and system themes, responsive from phone to desktop

Built with

  • JavaScript
  • Tailwind CSS v4
  • HTML
  • LocalStorage
  • Render

Case study · Web + Android app

Tax Return Helper

The problem

Self-employed drivers need to track income, expenses and mileage all year, then turn it into the right boxes on their HMRC Self Assessment return.

What I built

  • Quick add for income, expenses and business miles on every screen, saved to the right tax year
  • Income Tax and National Insurance estimates, and how much to set aside each month
  • The mileage allowance compared with actual car costs
  • Box-by-box figures to copy into the GOV.UK return, plus PDF export
  • English and Bengali, as a website and an Android app

Key decisions

  • React 19 with Vite and Tailwind CSS 4
  • The tax engine is covered by automated tests with Node's built-in test runner
  • Capacitor wraps the same code as an Android app, so one codebase serves web and mobile
  • No back end: data stays on the device, with backup and restore

Built with

  • React
  • Vite
  • Tailwind CSS
  • Capacitor
  • pdf-lib
  • Node test runner

Case study · Writing tool

ParaLine

The problem

Most free paraphrasing tools limit how much you can rewrite and merge your lines into one block, which breaks lists, scripts and subtitles.

What I built

  • Rewrites English text in six styles
  • Keeps every line separate, so the structure of the text survives
  • An offline mode that needs no AI service
  • An optional Gemini AI mode for higher-quality rewrites

Key decisions

  • The offline mode means the tool keeps working, and stays free, without any API key
  • Gemini is optional, not required, so the core tool has no running cost

  • JavaScript
  • Gemini API
