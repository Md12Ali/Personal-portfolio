How a project runs

Four clear stages, with you in the loop at each one.

  1. Discover

    We agree on goals, audience and what success looks like. I map the content, data and features before anything is designed.

  2. Design

    Wireframes first, then a distinct visual identity with type, colour and motion, prototyped so you can feel it early.

  3. Build

    Clean, tested code across the full stack: database, server and a fast front end, with 3D only where it earns its place.

  4. Launch & grow

    Deployment, SEO, analytics and marketing, so the site keeps working for you long after launch day.
